# LeadBoost — контекст проекта

Лендинг бренда LeadBoost (Nijat, Баку). Основная услуга — таргетированная
реклама, дополнительная — создание сайтов. Клиенты преимущественно в
Казахстане, цены в USD.

## Дизайн-референс и стиль

Базовая структура (секции, плавающий навбар-пилюля, нумерованные секции
01 СТУДИЯ / 02 ЧТО ДЕЛАЮ...) — изначально по референсу
https://horizonx.so/explore/cinderline (Cinderline от HorizonX), позже
переведена в тёмную тему. Поверх этого на `main` сейчас смёржен
редизайн **в духе ruslik.site** (тёмный необроутализм): толстые 2px
обводки `var(--border-dark)` и единый радиус 24px на ВСЕХ карточках
(fit-card/price-card/note-card/roi-box/form-card/p-face/work-slide —
специально унифицировано, не расходится по 18-28px как было раньше),
точечная сетка на фоне (`.cl-root::before`), супер-карточки с толстой
обводкой группируют аккордеоны (услуги, FAQ — класс `.super-card` +
`.pill-row`), мокап ноутбука в хиро (`.laptop-mock`), неоновый кружок
номера секции (38px, обводка+свечение акцентным жёлтым — `.sec-num
.circle`), двухцветные заголовки через `<Mark>` (жёлтое выделение слова).

Ещё два альтернативных редизайна лежат нетронутыми в ветках
`variant/dockspace-style` (минималистичный светлый SaaS, мокапы устройств,
центрированный хиро) и `variant/ruslik-style` (то же, что смёржено в main,
но без многоязычности — исторический артефакт, `main` актуальнее) — можно
поднять для сравнения, но `main` — рабочая версия.

Палитра: фон `#101014`, текст `#EDEDEA`, акцент — фирменный жёлтый `#ECEA0D`
(из логотипа LeadBoost), вторичный акцент `#D8D400`. Шрифты: **Hanken
Grotesk** (весь текст), **JetBrains Mono** (числа, теги, лейблы — намеренно
моноширинный, чтобы цифры не «прыгали» при count-up-анимациях).

Базовый размер некрупного текста (лейблы, описания, пункты списков)
намеренно поднят с исходных 10-13.5px до 14.5-16.5px по прямой просьбе
пользователя («чтобы посетители не мучали глаза») — не занижать обратно
при правках, ниже ~14px читается тяжело на тёмном фоне.

## Структура кода (чистая архитектура, НЕ смешивать обратно в App.jsx)

```
src/
├── main.jsx          — точка входа
├── App.jsx           — ТОЛЬКО композиция и разметка, без контента/конфига
├── config.js          — настройки владельца (токены, места, часы работы)
├── data.jsx            — ВЕСЬ контент по языкам: CONTENT.{ru,kk,en}
├── i18n.jsx             — UI-строки интерфейса по языкам (UI.{ru,kk,en}) + useLang
├── interactions.jsx    — императивные хуки (scroll, cursor, marquee, coverflow)
├── hooks.jsx            — базовые хуки (useReveal, Reveal, useTween)
├── widgets.jsx          — Scramble, WordReveal, CountMetric, TargetGame
├── icons.jsx             — SVG-иконки (кастомные + премиум из Envato)
├── styles.css            — все стили одним файлом
└── fonts/               — CookConthic (см. ниже про кириллицу)
```

Правки текста/цен/тарифов — только в `data.jsx` (менять во всех трёх
языковых блоках сразу: ru/kk/en). Правки UI-надписей (кнопки, лейблы,
футер) — в `i18n.jsx`. Правки токенов/лимитов — только в `config.js`.
Не хардкодить контент обратно в JSX разметку.

**Многоязычность (RU/KZ/EN)**: переключатель в навбаре (без смены URL,
клиентский стейт), по умолчанию у нового посетителя — русский, выбор
сохраняется в `localStorage`. Заявка в Telegram/mailto всегда на русском
независимо от языка сайта (её читает владелец, не посетитель) — см.
`RU = CONTENT.ru` в `App.jsx`. Казахский текст — машинный перевод, не
вычитан носителем, стоит проверить перед публичным запуском.

## Важные технические решения (не переделывать не глядя)

1. **Логотип встроен как base64 (`--loader:.png=dataurl`), не файлом.**
   Раньше был баг: esbuild с `--loader:.png=file` писал в JS относительный
   путь `"./logo.png"`, а `<img src="...">` резолвится браузером относительно
   HTML-страницы, а не JS-файла в `dist/` — из-за этого лого не грузилось
   (404). Инлайн-base64 полностью убирает эту категорию ошибок.

2. **Шрифт Cook Conthic (`src/fonts/`) не содержит кириллицы** — только
   латиница+цифры, один вес (Bold/700). Подключён через `@font-face` с
   `unicode-range`, применён ТОЧЕЧНО: wordmark «LEADBOOST» в футере и цены
   тарифов ($170/$290/$490). НЕ применять к русскому тексту — эффекта не
   будет (браузер молча откатится на Hanken Grotesk).

3. **Числа в JetBrains Mono (калькулятор, счётчики, теги «КЕЙС/01») —
   намеренно не трогать шрифтом/анимацией.** Табличные цифры нужны для
   ровного выравнивания при count-up. Не заменять на пропорциональный шрифт.

4. **Премиум-иконки** (`IconAds`, `IconWebDev`, `IconDesign`, `IconAnalyticsP`,
   `IconStrategy`, `IconKPI`, `IconConsultation`, `IconTransparency`,
   `IconCaseStudies`, `IconSuccess`, `IconSupport`, `IconConsultant`) —
   из купленного Envato-пака «65 Marketing Agency Line Icons», исходно
   мультицветные, пересобраны в `currentColor` (тень 16% непрозрачности +
   основная форма 100%), чтобы наследовать акцентный цвет вместо 4 случайных
   цветов пака. У них высокая детализация — **не уменьшать контейнеры
   меньше ~50-60px**, на 20-25px превращаются в нечитаемое пятно (проверено
   рендером через cairosvg).

5. **html/body фон = `#101014`** задан отдельно от `.cl-root` — без этого
   при овербаунс-скролле (особенно трекпад macOS) видно белый фон браузера.

6. **Telegram-форма отправляется через серверную функцию `api/telegram.js`**
   (Vercel), не напрямую из клиента. Токен и chat_id — переменные окружения
   `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` на Vercel (Settings →
   Environment Variables), их больше нет в `src/config.js` и в бандле
   `dist/main.js` — проверено grep'ом по собранному файлу. Локально в
   `npm run dev` (esbuild --servedir) функция `/api/*` не выполняется —
   это работает только через Vercel (прод или `vercel dev`), поэтому в
   локальной разработке форма ожидаемо уходит в mailto-фолбэк.

## Сборка

```bash
npm install
npm run dev      # разработка, автопересборка, http://localhost:8000
npm run build    # прод-сборка в dist/ (минификация + sourcemaps)
```

Деплой: `index.html` + папка `dist/` (без `.map`-файлов).
