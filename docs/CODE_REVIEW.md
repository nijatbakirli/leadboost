## Фикс сборки: логотип не загружался (404 на /logo.png)

**Причина:** esbuild с `--loader:.png=file` записывал в JS-бандл относительный
путь `"./logo.png"`. Такой путь, использованный как `<img src="...">`,
браузер резолвит относительно адреса HTML-страницы (корня сайта), а не
относительно расположения самого JS-файла в `dist/` — отсюда запрос
`http://.../logo.png` вместо `http://.../dist/logo.png` и 404 при любом
локальном запуске.

**Решение:** loader сменён на `dataurl` — логотип теперь встраивается в
`main.js` как base64-строка. Отдельного файла `dist/logo.png` больше нет,
поэтому сама категория ошибки («не нашёлся путь к ассету») исключена.

## Интеграция премиум-иконок (Envato, 65 Marketing Agency Line Icons)

12 SVG-иконок из купленного пака переведены из фирменной мультицветной палитры
(розовый/оранжевый/фиолетовый/голубой поверх тёмно-серой линии) в единую
акцентную схему сайта: фоновые/теневые фигуры — `currentColor` с 16% непрозрачности,

`var(--accent)` так же, как остальные иконки сайта, вместо внесения четырёх
случайных цветов, конфликтующих с единой жёлтой палитрой бренда.

- **Принципы** (04) — иконка на лицевой стороне флип-карточки

## Подключение шрифта Cook Conthic (пользовательский, куплен отдельно)

**Технический факт:** шрифт не содержит кириллицы (только латиница + цифры,
403 глифа, единственное начертание — Bold/700). Проверено через `fonttools`.
Применение «на весь сайт» буквально означало бы отсутствие видимого эффекта
на 95%+ текста (весь русский текст молча падает на Hanken Grotesk).

**Решение:** подключён через `@font-face` с `unicode-range: U+0000-024F, U+2000-206F`
— браузер посимвольно берёт Cook Conthic для латиницы/цифр и откатывается на
Hanken Grotesk для кириллицы в той же строке, без ручного разделения текста.

Применён точечно к двум крупным display-элементам с чистой латиницей/цифрами:
- Wordmark «LEADBOOST» в футере
- Цены в тарифах ($170 / $290 / $490)

**Сознательно не применён** к числовым элементам в стиле JetBrains Mono
(калькулятор, счётчики метрик, hero-чипы, теги «КЕЙС / 01») — там табличные
(моноширинные) цифры нужны для ровного выравнивания и плавной анимации
count-up; проприетарный display-шрифт с пропорциональными цифрами это бы сломал.
